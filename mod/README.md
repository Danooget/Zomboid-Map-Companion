# Zomboid Map Companion — mod files

This directory contains the Build 42 Workshop Lua scripts and `mod.info` taken from the author's `LiveWebMap.7z` archive.

The corresponding complete original Java source and Gradle project are in [`../../java/`](../../java/). This source-only repository does **not** contain the compiled `LiveWebMap.jar` or the Chromium native runtime. The Lua entry points refer to the compiled Java classes.

`LiveWebMap` is the original internal identifier and remains unchanged to keep existing installations compatible. The public-facing product name is **Zomboid Map Companion**.
